# astroarch-bridge

Backend daemon per **Astroarch Interface** (app Android di Zarletti-Osservatorio Jupiter).

Replica in tempo reale lo stato di **INDI**, **Ekos** e **PHD2** verso un'app mobile via REST + WebSocket. Non modifica AstroArch: si collega ai servizi già attivi tramite i loro protocolli nativi.

## Architettura

```
       App Android                     RPi5 / AstroArch
   ┌─────────────────┐    Tailscale    ┌─────────────────────────┐
   │ Astroarch       │ ◄────────────► │ astroarch-bridge :8765  │
   │ Interface       │   HTTPS / WSS   │  ├─ REST /api/*         │
   └─────────────────┘                 │  ├─ WS   /ws/state      │
                                       │  └─ WS   /ws/frames     │
                                       │           │             │
                                       │   INDI :7624 (TCP XML)  │
                                       │   PHD2 :4400 (JSON-RPC) │
                                       │   ~/Pictures/Ekos       │
                                       └─────────────────────────┘
```

## Componenti

| Modulo | Cosa fa |
|---|---|
| `indi/protocol.py` | Parser XML INDI incrementale (chunk parziali, recovery) |
| `indi/client.py` | Client TCP asincrono con reconnect exponential backoff |
| `phd2/client.py` | Client JSON-RPC PHD2, eventi + RPC (guide/dither/stop/loop) |
| `images/processor.py` | FITS → JPEG con auto-stretch MTF, debayer, HFR/star count |
| `images/watcher.py` | Watch su `~/Pictures/Ekos`, stabilization-aware |
| `state.py` | State manager condiviso, listener pattern |
| `ws/hub.py` | Broadcast WebSocket con backpressure (drop oldest) |
| `routes/*.py` | REST API per mount/camera/focuser/filter/guide/observatory/files/INDI panel |
| `app.py` | Factory FastAPI + lifespan |

## Installazione su AstroArch (RPi5)

```bash
# Copia o clona il backend sul RPi
scp -r backend/ astroarch@RPI_IP:/tmp/

# Sul RPi:
ssh astroarch@RPI_IP
cd /tmp/backend
sudo bash deploy/install.sh --user astroarch
```

A fine installazione viene mostrato:
```
URL:   http://100.x.y.z:8765
Token: <auto-generated>
```

Salva il token: serve all'app Android per autenticarsi.

## Configurazione (env vars)

Tutte con prefisso `ASTROARCH_`:

| Variabile | Default | Descrizione |
|---|---|---|
| `ASTROARCH_HOST` | `0.0.0.0` | bind address |
| `ASTROARCH_PORT` | `8765` | porta HTTP |
| `ASTROARCH_TOKEN` | (auto) | bearer token; se vuoto, generato e salvato |
| `ASTROARCH_TOKEN_FILE` | `~/.config/astroarch-bridge/token` | path token |
| `ASTROARCH_INDI_HOST` | `127.0.0.1` | host indiserver |
| `ASTROARCH_INDI_PORT` | `7624` | porta indiserver |
| `ASTROARCH_PHD2_ENABLED` | `true` | abilita client PHD2 |
| `ASTROARCH_PHD2_HOST` | `127.0.0.1` | host PHD2 |
| `ASTROARCH_PHD2_PORT` | `4400` | porta PHD2 |
| `ASTROARCH_IMAGES_DIR` | `~/Pictures/Ekos` | cartella catture FITS |
| `ASTROARCH_IMAGE_MAX_DIM` | `1600` | lato max JPEG inviato |
| `ASTROARCH_LOG_LEVEL` | `INFO` | DEBUG/INFO/WARNING/ERROR |

## API REST (sintesi)

Tutte richiedono `Authorization: Bearer <token>` (eccetto `/healthz`).

| Endpoint | Cosa fa |
|---|---|
| `GET /healthz` | health (no auth) |
| `GET /api/system/snapshot` | stato globale completo |
| `GET /api/indi/devices` | elenco device INDI |
| `GET /api/indi/devices/{dev}/properties` | tutte le proprietà del device |
| `POST /api/indi/devices/{dev}/properties/{name}` | imposta valori (Switch/Number/Text) |
| `GET/POST /api/mount/*` | status, goto, park/unpark, abort, track, slew |
| `GET/POST /api/camera/*` | expose, abort, cooler, binning, gain/offset, frame_type |
| `GET/POST /api/focuser/*` | status, abs, rel, abort |
| `GET/POST /api/filter_wheel/*` | status, select, rename |
| `GET/POST /api/guide/*` | status, start, stop, dither, loop, clear_calibration, pause |
| `GET/POST /api/observatory/*` | dome, dust_cap, flat_panel, weather |
| `GET /api/files/recent` | elenco FITS recenti |
| `GET /api/files/preview?path=...` | JPEG preview di un FITS |

## WebSocket

- `GET /ws/state?token=...` — clone live: snapshot iniziale + eventi push (property_def, property_set, indi_message, phd2_event, phd2_live, frame_meta, connection)
- `GET /ws/frames?token=...` — stream JPEG: header JSON + bytes JPEG per ogni nuovo FITS
